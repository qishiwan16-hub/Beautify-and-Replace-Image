# 主题一键换图

这是基于原版“主题一键换图”的二改版，原作者为毛毛雨。原有主题 CSS 图片替换、预设和 IndexedDB 行为保持不变。

预设管理支持通过“切换”按钮应用指定预设，也可使用旁边的“保存”按钮把当前图片替换配置覆盖到该预设。当前使用的预设会显示绿色指示灯；再次点击当前项的“默认”按钮会恢复主题原图并取消预设。保存新预设或覆盖预设后会自动标记为当前；手动换图、重置或清理当前配置后，旧预设的当前标记会自动取消。删除预设时会一并释放不再被当前配置或其他预设引用的图片缓存；重复导入内容相同的本地图片时会按内容哈希合并。

创作模式提供批量下载、批量导入本地图片和批量链接导入。批量链接按图片序号逐行映射；粘贴后点击“插入替换”可写入逐项预览，某一行填写“空”时会保留对应图片，不执行替换。链接清单使用一次索引和分批渲染，打开页面时不会再同步创建全部预览。链接替换使用插件内独立页面，并显示图片加载和替换进度；替换时会把当前配置及所有已有预设的旧链接键迁移到新链接，原预设无需重新导入。替换只更新当前主题 CSS 编辑内容，仍需在酒馆主题界面手动保存。

批量下载会先显示当前主题 CSS 原链接清单、序号和预览图；每项可上传本地图片替换本次 ZIP 内容，也可点击“还原”回到 CSS 原图。所有图片统一按“美化名-序号”命名。打包完成后会显示下载按钮和约 24 小时有效的后端直链；设置中可选择手动下载或自动下载，手动下载不会在打包完成前自动保存文件。生成直链时，完整 ZIP（包括本次选择的本地替换图）会上传到酒馆后端。批量导入支持直接选择本插件下载的 ZIP 或普通 ZIP，并按压缩包内图片文件名匹配替换位置。下载、导入和链接替换会在实际处理完成后显示酒馆通知。关闭插件面板会取消仍在进行的后端或扩展更新检测，但不会中断已经开始的扩展更新。

## 安装

在 SillyTavern 的扩展管理器中安装：

`https://github.com/qishiwan16-hub/Beautify-and-Replace-Image`

或在 `data/<账户>/extensions/third-party` 目录克隆本仓库。

## 后端存储

后端插件仓库：

`https://github.com/qishiwan16-hub/Backend-for-image-replacement-and-UI-enhancement`

将后端克隆到 `SillyTavern/plugins/image-replacement-ui-enhancement`，启用 `enableServerPlugins` 后重启酒馆。扩展打开时会检测 `/api/plugins/image-replacement-ui-enhancement/status`；检测到后端时，配置和图片保存到酒馆后端，否则自动继续使用浏览器 IndexedDB。

## 更新

扩展工具栏的“检查更新”会调用 SillyTavern 官方扩展更新接口。更新成功后会重新注入模块脚本并尝试热加载；若当前环境不允许热加载，刷新酒馆页面即可完成加载。
